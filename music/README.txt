把你喜欢的 mp3 / m4a / ogg 放进这个文件夹，然后编辑同目录的 playlist.json：

[
  { "title": "歌名（显示在设置里）", "file": "music/文件名.mp3" },
  { "title": "第二首",               "file": "music/another.mp3" }
]

刷新网页后，它们会出现在 设置 → 🎵 背景音乐 的列表里（内置 5 首后面）。
也可以在设置里点"📂 添加本地音乐"临时选文件，仅本次打开有效。

可免费使用（需遵守各站使用条款/署名要求）的日系 BGM 站点：
- 魔王魂         https://maou.audio/
- DOVA-SYNDROME  https://dova-s.jp/
- 甘茶の音楽工房 https://amachamusic.chagasi.com/
- OtoLogic       https://otologic.jp/

注意：商业流行歌曲有版权，仅限自己本机使用，不要把包含它们的整个文件夹公开发布。
